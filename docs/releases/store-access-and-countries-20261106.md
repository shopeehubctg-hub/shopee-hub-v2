# Store management and country access

- Permission Settings has a compact store directory with search, country and service-status filters.
- Super Admins can pause or end service after reviewing access impact. History is retained. Reactivating a store requires separate access approval before customer and manager accounts can use it again.
- Project grouping gives related storefronts one selector entry. Country options remain restricted to the storefronts each user can access. SkinDae's existing MY/SG grouping is preserved.
- Late Shipment keeps its existing Production behavior. Example orders are available only in Staging.
