# Dashboard release — 27 October 2026

## Packages & Pricing

- Grid and spreadsheet-style List views share prices, status, history and existing package actions.
- Combine Long Term / Monthly tabs with status filters and search.
- List shows separate MY/SG prices, promotion dates, listing SKUs, inventory quantities and versions, with sticky headings and package names.
- Render 30 records initially with Show more. View switching retains Fulfillment selection; changing filters clears it.
- Ending a Long Term package changes status to Expired while retaining its original duration category.
- Eight clearly labeled, read-only sample packages remain available only to Super Admin on the fixed Staging hostname. They are not seeded into databases or Sheets and cannot be edited, exported or published.

## Account — Super Admin preview

- Compact monthly billing records grouped into Malaysia and Singapore sections, with separate editable company context and current Store Selector names.
- Search by Entity, inspect row details, select multiple visible records and preview effective-invoice-month Rate Card changes.
- Shared Rate Cards support fixed fees, percentages and whole-month tiers. Historical versions and locked previews remain distinct; archived cards disappear from new selections.
- October 2026 source defaults are applied per billing project. Internal NEW uses the confirmed A–E tiers with the RM4,000 cap only on tier E.
- SG preview converts SGD sales to MYR before tier selection. Internal, Berlanco SG and GOHERB SG use 3.2; Bonlife uses the evidenced preceding Service Period's BNM monthly average.
- Current unique selector matches clear the Client mapping warning. Ambiguous/missing matches remain marked for attention; display matching does not create a financial ledger binding.
- Invoice Month refers to the previous month's Service Period. Preview changes reset on refresh; missing income evidence stays unknown.

## Compatibility and scope

- Production retains the existing store-only Add/Edit Store form and persistence path, including links and Ads Top Up owner. It does not require unapproved Account tables or RPCs.
- The new Add Store Account setup remains a Staging preview pending explicit database activation and atomic persistence support.
- No Account migrations are executed, financial records imported, or income invented by this release. Rate/mapping preview is not a persistent billing activation.
