# Shopee Hub Dashboard: first-time login and password reset

1. Open the Shopee Hub Dashboard and choose **Forgot password?**
2. Enter the email address that Shopee Hub granted access to. Select **Send password link**.
3. Open the email message and follow its time-limited link. If no message arrives, check spam and ask the Shopee Hub Specialist to confirm that your individual email is active.
4. Set a unique password of at least 12 characters. The link opens the Dashboard after the password is saved.
5. Later, sign in with the same email and your own password. If you forget it, repeat steps 1–4.

Each person uses an individual portal account. A shared temporary password is no longer part of this flow. Team members must not forward a password link. A link that expires must be requested again.

Administrators grant or remove each person's store and module access separately. Sending a password link does not grant access to an unregistered email.

This guide replaces the first-login section of the earlier PDF once the email-link release has passed staging and is deployed.
